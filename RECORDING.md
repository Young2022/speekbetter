# 示范音频录音清单

按模块录。每一句念一遍，导出成 WAV，命名成 `<句子 id>.wav`，放进 `assets/audio/`。

**格式要求**：PCM / 单声道 / 22050 Hz / 16 bit

> 不用自己转格式：把手机录的原始文件拖进 `tools/convert-audio.html`，
> 浏览器会直接转好并按句子 id 命名下载。

> 生活/职场/旅行句念屏幕上那一句；雅思/托福/四六级句念「示范回答」那一段。
